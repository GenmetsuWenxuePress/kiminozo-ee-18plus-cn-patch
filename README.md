## 📥 使用方法

### 系统要求

- Windows 10 / 11
- Steam 正版《Kimi ga Nozomu Eien ~Enhanced Edition~》（英文版）
- DLC《Another Episode Collection+》（如需 DLC 汉化）
- 约 3GB 空闲磁盘空间

### 安装步骤

1. 从 **[Releases](https://github.com/GenmetsuWenxuePress/kiminozo-ee-18plus-cn-patch/releases)** 下载 `Kiminozo_EE_CN_Installer_v1.0.exe`
2. 双击运行（未签名程序，SmartScreen 提示 →「更多信息」→「仍要运行」）
3. 阅读首屏说明并勾选同意 → 下一步
4. 安装器自动识别游戏目录 → 勾选要安装的组件
5. 点击「开始安装」→ 等待完成（约 1.1GB 数据写入，数分钟）

### 组件说明

| 组件 | 文件 | 依赖 |
|---|---|---|
| 18+ 补丁（EER 层） | patch00d + patch01m + patch00m | 无 |
| 本体汉化（中文） | patch00m（v20，含 18+ 剧情文本） | 无（完全独立；不装 EER 层时 H 场景可能缺图） |
| DLC 汉化 | pack.bin + pack00m.bin | 需已安装 DLC（安装器会自动检测并提示） |

### 重复运行 / 卸载

- 再次运行安装器：自动检测每一项状态，已安装项显示「已安装」，不会重复安装；
- 卸载：运行安装器 → 选择卸载 → 自动还原安装前备份。

## 🔧 汉化技术全记录（过程 + 问题与解决）

> 本章记录这个补丁是怎么做出来的、踩过哪些坑、如何解决——包括已证伪的路线，供后来者参考。

### 总览

```
[Steam 英文版游戏（干净基底）]
        │
        ▼
① 容器格式逆向：.egpack 加密格式 + patchNNx.bin 分层补丁容器
        │
        ▼
② 全量翻译：本体 4,964 记录 + DLC 3,688 条（AI 批量 + 校对）
        │
        ▼
③ 字体层重建（修复方框）+ 容器重组 + 清洁度全量校验
        │
        ▼
④ 与 EER 18+ 层整合（文本层汉化合并；图形/视频层原样）
        │
        ▼
⑤ 单文件安装器（1.1GB 全内嵌：检测 / 备份 / 校验 / 卸载）
```

### 1️⃣ 游戏文本架构

- 剧本 = `.egpack` 容器（XOR 加密），每条记录含 11 个 token 字段；
- 游戏本体 / EER 层 / DLC 各自拥有文本容器（`patch00m.bin` / `pack.bin` / `pack00m.bin`）；
- 汉化方式 = **同机制重建容器**（结构、长度、加密全部保持），与原版的差异即翻译本身。

### 2️⃣ 翻译管线

- 全量提取 → AI 批量翻译（分块进行）→ 逐条校对（多波次复核）→ 术语表统一；
- 称谓按场景决策（如餐厅名「天空神殿」、昵称「文绪酱」——不同场景不同处理，不做全局一刀切）；
- 覆盖：本体 4,964 个剧本记录（含 EER 18+ 文本层）+ DLC 3,688 条 = **100%**。

### 3️⃣ 字体层与「方框」攻坚（本项目最大难点）

- **问题**：backlog 等场景中部分中文显示为「□」（方框）。
- **过程**：从零开始做单变量实验 —— v18（5 个字体）✗ → v19（2 个字体）✓ → v20（3 个字体）✓
- **根因**：容器内**字体条目数过多**，污染引擎字体池。
- **终解**：v20 = 3 个字体（含片尾 staff roll 必需的 BIZ 字体），方框全部消除。
- **验证**：v20 容器与原版全量 diff —— 4,328/4,964 记录一致，全部差异均为预期汉化。

### 4️⃣ 问题档案（踩坑与解决）

| # | 问题 | 根因 | 解决 |
|---|---|---|---|
| 1 | 中文显示「方框」□□□ | 字体条目数过多污染字体池 | v20 三字体方案（见上） |
| 2 | Ending list 无法点击 | **原作设计**（读取存档通关标记） | 非汉化问题，原版实测同样如此 |
| 3 | DLC 显示「已安装其他版本」 | 检测语义误导（全新游戏自带原版文件） | 改为「未安装 + 安装时将自动备份现有文件」 |
| 4 | 已安装后点安装仍会重装 | 未做哈希级跳过 | 哈希级检测 +「✓ 无需安装」零拷贝 |
| 5 | 安装器图标不更新 / 版本号 0.0.0 | Windows 图标缓存；编译器预嵌空版本资源 | 重建图标缓存；双语言槽注入版本信息 |
| 6 | 中文文档零散、安装繁琐 | — | 单文件安装器：全内嵌 + 一键 + 备份 + 卸载 |

### 5️⃣ 单文件安装器

- **架构**：C# 原生 exe（.NET Framework，Win10/11 自带运行时）+ 尾部附着全量载荷（运行时流式读取自身，零临时解压、零额外磁盘占用）；
- **自动检测游戏目录**：Steam 注册表 + libraryfolders.vdf + 常见路径兜底；
- **组件完全独立**：三个组件可任意勾选；DLC 未安装时禁用对应组件并引导去 Steam；
- **安全设计**：安装前自动备份、安装后全量哈希校验、游戏运行检测、磁盘空间检测、完整日志；
- **界面**：浅色主题；首屏说明（许可勾选，不同意禁止安装）；进度与结果如实显示。

## ❓ 常见问题

**Q：进游戏还是英文？**
A：Steam 更新 / 校验文件会把汉化层还原 —— 重新运行安装器即可（自动检测，只补缺失部分）。

**Q：DLC 汉化装不了？**
A：先在 Steam 安装 DLC《Another Episode Collection+》，安装器会自动检测并放开对应组件。

**Q：还能看到个别错译？**
A：AI 批量翻译 + 校对仍可能有疏漏，欢迎反馈。

**Q：如何卸载？**
A：重新运行安装器 → 选择卸载 → 自动还原安装前备份。

**Q：单独下载的补丁文件怎么用？**
